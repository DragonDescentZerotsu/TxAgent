# Historical one-pass LoRA/RL results

This folder retains two result reports from the retired Starling one-pass
LoRA/RL experiments with GPT-OSS-120B and GPT-OSS-20B.

- [Base validation results](ONE_PASS_BASE_VALID_RESULTS.md): the original
  one-pass base-model validation comparison.
- [Visible-prefetched results](VISIBLE_ONE_PASS_VALID_RESULTS.md): the
  visible-prefetched base validation and bounded RL smoke results.

The training executables, configuration recipes and operational/design
guidance have been retired. The result reports remain historical evidence.
