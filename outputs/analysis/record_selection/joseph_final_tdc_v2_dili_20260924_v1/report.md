# Joseph final collection: TDC-v2 DILI

Two complete 96-query test arms are installed in the [final collection](../../../paper/assay_transfer_harness/joseph/final/collection.json), with per-query requests, predictions, traces, and served-route provenance. The direct arm scored macro F1 0.829711 and accuracy 0.833333; direct plus indirect scored macro F1 0.760436 and accuracy 0.770833. Full confusion counts and route counts are in [results.tsv](results.tsv).

Both arms use the frozen `ga075_mc025_label000` direct panel and the same test query prior. The indirect arm adds 50 L2–L7 records per query using the parent-disjoint top-100 universe and `sqrt(DILI tool score × semantic bucket weight)` with tied diversity terms. Its semantic extension manifest is marked `candidate_unreviewed`; the final arm preserves that status. The direct arm used upstream-v3 prompt guidance and mixed OpenRouter/RunPod execution, while indirect used the DILI mixed-v3 prompt and OpenRouter only, so their difference is descriptive rather than a controlled causal effect of indirect records.

The [validation and paired-error analysis](../dili_tdc_v2_geomean_parent_disjoint_valid_20260924_v1/report.md) documents the indirect false-positive pattern. A [same-prompt direct-only validation control](../dili_tdc_v2_direct_same_prompt_valid_20260924_v1/report.md) scored macro F1 0.831541 with five false positives among 17 negatives; the indirect winner scored 0.825465 with six. Only two paired predictions changed, and their upstream OpenRouter providers differed between arms. Most validation false positives were already present without indirect records. [provenance.json](provenance.json) pins the source selections, installed arms, and collection index. Existing final arms remain unchanged.
