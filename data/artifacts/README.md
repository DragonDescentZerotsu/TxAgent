# Data artifacts

This tree is audit-only: it contains compact receipts, migration records, and
decision evidence that are not required build or runtime inputs. Active gold
data and its version-specific mappings belong under `data/gold_labels/`; active
evidence data belongs under `data/evidence_libraries/`; shared reusable caches
belong under `data/caches/`; complete retired products belong under
`data/legacy/`. Do not add compatibility symlinks here.
