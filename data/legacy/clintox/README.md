# ClinTox legacy archive

ClinTox was retired from the active evidence-library registry during the data
layout v1 migration. Its task code, tests, acquired and derived sources, gold
labels, normalized-v7 library, and tracked source archives are preserved here.

The historical `data/starling_data/clintox`, `data/conditioned_benchmark/ClinTox`,
and `outputs/chembl_tool/tasks/clintox` paths remain read aliases. New active
builders and task registries must not select this archive.
