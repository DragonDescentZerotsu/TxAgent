# Analysis reports

This directory is the central index for cross-task scientific analyses. Analysis
code and large generated artifacts may remain beside their owning pipeline, but
each completed analysis should have one concise Markdown report here with its
scope, method, findings, artifact links, and unresolved issues.

Current reports:

- [Pair-bucket replicate variance](pair_bucket_replicate_variance.md)
- [Measurement routing and final-tail pruning](measurement_routing_and_final_tail_pruning.md)

Existing historical reports are not moved automatically because their paths may
be referenced by manifests or experiment documentation. They can be indexed here
when revisited.
